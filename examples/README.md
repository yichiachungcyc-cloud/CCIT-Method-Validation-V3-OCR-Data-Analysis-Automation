# Synthetic fixture / 虛構範例

`synthetic_records.csv` is generated by `demo.synthetic_rows()`. Every name begins with DEMO; values and identifiers are invented. There is no company report, OCR transcript, signature or original sample data in this fixture.

此 CSV 完全由程式產生，名稱、編號與數值皆為虛構。它測試下游處理，不測試掃描辨識。

Run `python demo.py` to reproduce downstream outputs. The chart published in `docs/assets/` is copied from this synthetic run.
